# CS-370
Pirate Intelligent Agent 
## Project Overview

For this project, I developed a pirate intelligent agent that uses reinforcement learning and a neural network to navigate a maze and find treasure. The goal was for the agent to learn which actions would lead it toward the treasure while avoiding inefficient or unsuccessful paths.

The starter code provided the basic environment for the project, including the `TreasureMaze` class, the `GameExperience` class, and parts of the training process. I also received the basic structure for building and training the neural network. My work involved completing and modifying the missing sections of the code, including the `build_model()` and `qtrain()` functions, so the intelligent agent could learn through experience. I implemented the neural network architecture, experience replay, training process, and target network updates needed for Deep Q-learning. I also worked through errors and adjusted the code so the model could successfully train and improve its performance.

## Connection to Computer Science

Computer scientists solve problems by using computational thinking, programming, algorithms, data, and technology to create solutions. Their work matters because computer science is used in almost every industry, from transportation and communication to healthcare, business, and artificial intelligence. This project showed me how computer science can be used to create systems that learn from experience instead of relying entirely on instructions written by a programmer.

I approach a problem as a computer scientist by first understanding the problem and identifying what information and resources are available. From there, I break the problem into smaller parts, determine what algorithms or techniques could be useful, implement a solution, and test the results. When something does not work, I use the errors and results to identify what needs to change. The pirate intelligent agent project reinforced this process because I had to understand how the maze, rewards, neural network, and training process worked together before I could successfully improve the agent.

Computer scientists also have ethical responsibilities to both the end user and the organization. When developing AI systems, I need to consider whether the system is reliable, fair, secure, and being used for its intended purpose. I also have a responsibility to protect user information and avoid creating systems that could cause unnecessary harm. For an organization, responsible development means creating software that meets requirements while also considering security, maintainability, cost, and potential risks. This course helped me understand that being a computer scientist is not just about making technology work; it is also about making thoughtful decisions about how that technology affects people.
